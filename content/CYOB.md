# HSA

# Gym
- $1,000 per point and can use both points. 
- Can be used for fitness centers or sports leagues, indoor fields, etc

- Taxable 
- Can be used for family membership but not for something like kids sports you aren’t a part of 
- Need itemized gym invoice
