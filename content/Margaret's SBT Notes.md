7. Review all release notes and refer to company for all updates and document impactful changes.  
    

8. Determine with R&D whether they want the updated Loss Costs (LC) & Increased Limits Factors (ILF) 
    
9. Determine with Underwriting whether they want the updated Rules (RU) and Forms (FO) changes. 
    

10. Pull all dates for the above 
    

11. Developer will install the latest SBT Update in their local machine 
    
12. BA & Developer will review the update using the PCA tool 
    
13. DEV will merge the code from the PCA tool into the branch.   
    

14. Forms & Ratebooks are loaded separately and directly to each environment.  
    

15. BA will review the update in the environment and write requirements as needed 
    

16. Determine with Underwriting how they want to use the change to Rules, Forms, Rates 
    

17. BA/DEV will ensure that other streams are informed of changes in the updates as there may be additional work for these teams 
    

18. DEV will complete any modifications that are needed. 
    
19. QA will test 
    
20. DEV will promote
