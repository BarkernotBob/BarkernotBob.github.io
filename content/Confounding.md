A confounding variable is often the root of spurious proposed correlations. This is when the true cause of a result is overlooked, and another incorrect cause is attributed. It would be like saying "I've never seen it rain while it's sunny outside, so when the sun's out it must burn off rain before it reaches the earth." Whenever a causal correlation is drawn between 2 things, one must ask the question of whether a confounding variable might be present.

# Example
Consider the following logic:
* I started exercising more
* I didn't lose weight
* Exercising doesn't help you lose weight
What's the issue here? While it is logically *possible* from only the info above that exercise doesn't help with weight loss, it does not prove it. Consider the following addition:
* I started exercising more
* **I changed from a job on my feet to a desk job**
* I didn't lose weight
* Exercising doesn't help you lose weight
Here, there is a *confounding* variable. While it is true that the individual didn't lose weight, it does not mean that the exercise was ineffective. To truly measure such a claim, all external variables would need to be accounted for.
